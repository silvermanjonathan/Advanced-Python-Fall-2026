1. Even or Odd

From Codewars: Even or Odd, 8 kyu. Uses % (session 6) and return (session 2).

Write a function even_or_odd(number). It takes a whole number. It returns the string "Even" when the number is even and the string "Odd" when it is odd.

Put these test lines under your function. A function that works prints the target output.

print(even_or_odd(4))
print(even_or_odd(7))
print(even_or_odd(0))
print(even_or_odd(-3))

Odd
Even
Odd
Stuck? Open one hint at a time. The answer is inside the last hint.

An even number divides by 2 with nothing left over. % gives what is left over.

The gate is if number % 2 == 0:. Under it, return "Even".

Jonathan_codewars.py

def even_or_odd(number):
    if number % 2 == 0:
        return "Even"
    else:
        return "Odd"

print(even_or_odd(4))
print(even_or_odd(7))
print(even_or_odd(0))
print(even_or_odd(-3))
verified output
Even
Odd
Even
Odd

-3 % 2 is 1, so the function works for numbers below zero as well. Session 4 used % with a negative number the same way.

2. Is n divisible by x and y?

From Codewars: Is n divisible by x and y?, 8 kyu. Uses % (session 6) and and to join two comparisons (session 2).

Write a function is_divisible(n, x, y). It returns True when n divides by x with nothing left over and also divides by y with nothing left over. Otherwise it returns False.

Put these test lines under your function. A function that works prints the target output.

print(is_divisible(12, 3, 4))
print(is_divisible(12, 3, 5))
print(is_divisible(100, 5, 10))
target output

True
Stuck? Open one hint at a time. The answer is inside the last hint.

n % x == 0 is a comparison. Its value is True or False.

A function can return the value of a comparison. Join the two comparisons with and, and return what that gives. No if is needed.

Jonathan_codewars.py

def is_divisible(n, x, y):
    return n % x == 0 and n % y == 0

print(is_divisible(12, 3, 4))
print(is_divisible(12, 3, 5))
print(is_divisible(100, 5, 10))
verified output
True
False
True

12 divides by 3 and by 4, so the first line prints True. 12 does not divide by 5, so and gives False on the second line.

3. Sum of positive

From Codewars: Sum of positive, 8 kyu. Uses an accumulator with a gate (session 1).

Write a function sum_of_positive(numbers). It takes a list of numbers. It returns the total of the numbers that are more than 0. Numbers below 0 are left out of the total.

For a list with no numbers above 0, it returns 0.

Put these test lines under your function. A function that works prints the target output.

print(sum_of_positive([1, -4, 7, 12]))
print(sum_of_positive([-1, -2, -3]))
print(sum_of_positive([]))
target output
20
0
0
Stuck? Open one hint at a time. The answer is inside the last hint.

Start a variable total at 0 before the loop. This is the accumulator from session 1.

Inside the loop, the gate if n > 0: decides whether n is added to total.

Jonathan_codewars.py

def sum_of_positive(numbers):
    total = 0
    for n in numbers:
        if n > 0:
            total = total + n
    return total

print(sum_of_positive([1, -4, 7, 12]))
print(sum_of_positive([-1, -2, -3]))
print(sum_of_positive([]))
verified output
20
0
0

For the empty list the loop makes no passes, so total is still 0 when it is returned.

4. Find the smallest integer in the array

From Codewars: Find the smallest integer in the array, 8 kyu. Uses a best-so-far variable (session 1).

Write a function smallest(numbers). It takes a list of whole numbers with at least one number in it. It returns the smallest number in the list.

Codewars calls a list an array. Integer is the name for a whole number.

Put these test lines under your function. A function that works prints the target output.

print(smallest([34, 15, 88, 2]))
print(smallest([34, -345, -1, 100]))
print(smallest([7]))
target output
2
-345
7
Stuck? Open one hint at a time. The answer is inside the last hint.

Keep the smallest number seen so far in a variable. Start it at numbers[0], the first number in the list.

Inside the loop, the gate if n < best: decides whether n replaces best.

Jonathan_codewars.py

def smallest(numbers):
    best = numbers[0]
    for n in numbers:
        if n < best:
            best = n
    return best

print(smallest([34, 15, 88, 2]))
print(smallest([34, -345, -1, 100]))
print(smallest([7]))
verified output
2
-345
7

Starting best at 0 would be a bug: for the list [34, 15, 88, 2] the function would return 0, and 0 is not in the list.

5. Reversed Strings

From Codewars: Reversed Strings, 8 kyu. Uses a string accumulator and + to join strings (session 3).

Write a function reverse(text). It takes a string and returns the same letters in the opposite order.

Put these test lines under your function. A function that works prints the target output.

print(reverse("world"))
print(reverse("stressed"))
print(reverse("a"))
target output
dlrow
desserts
a
Stuck? Open one hint at a time. The answer is inside the last hint.

Start with the empty string, out = "", and add one letter on each pass of the loop.

out + ch puts the new letter at the end. ch + out puts the new letter at the front.

Jonathan_codewars.py

def reverse(text):
    out = ""
    for ch in text:
        out = ch + out
    return out

print(reverse("world"))
print(reverse("stressed"))
print(reverse("a"))
verified output
dlrow
desserts
a

Each new letter goes in front of the letters already in out, so the last letter of text ends up first.

Put the five vowels in a list at the top of the file: VOWELS = ["a", "e", "i", "o", "u"].

Start count at 0. Inside the loop, the gate if ch in VOWELS: decides whether to add 1 to count.

Jonathan_codewars.py

VOWELS = ["a", "e", "i", "o", "u"]


def count_vowels(text):
    count = 0
    for ch in text:
        if ch in VOWELS:
            count = count + 1
    return count

        if ch not in VOWELS:

8. Rock Paper Scissors!

From Codewars: Rock Paper Scissors!, 8 kyu. Uses a dictionary lookup and a flat if, elif, else (session 6).

Write a function rps(move1, move2). Each move is "rock", "paper" or "scissors". Rock beats scissors, scissors beats paper, and paper beats rock.

The function returns "Player 1 won!" when move1 beats move2, "Player 2 won!" when move2 beats move1, and "Draw!" when the two moves are the same.

Put these test lines under your function. A function that works prints the target output.

print(rps("rock", "scissors"))
print(rps("scissors", "rock"))
print(rps("paper", "paper"))
print(rps("paper", "rock"))
target output
Player 1 won!
Player 2 won!
Draw!
Player 1 won!
Stuck? Open one hint at a time. The answer is inside the last hint.

Session 6 kept the rules in a dictionary: each key beats its value. BEATS = {"rock": "scissors", "paper": "rock", "scissors": "paper"}.

Check for a draw first with if move1 == move2:. Then BEATS[move1] is the move that move1 beats. Compare it with move2.

Jonathan_codewars.py

# each key beats its value: rock beats scissors
BEATS = {"rock": "scissors", "paper": "rock", "scissors": "paper"}


def rps(move1, move2):
    if move1 == move2:
        return "Draw!"
    elif BEATS[move1] == move2:
        return "Player 1 won!"
    else:
        return "Player 2 won!"

print(rps("rock", "scissors"))
print(rps("scissors", "rock"))
print(rps("paper", "paper"))
print(rps("paper", "rock"))
verified output
Player 1 won!
Player 2 won!
Draw!
Player 1 won!

The function has three gates in one flat chain. Without the dictionary it would need a gate for each of the nine pairs of moves.

9. Count characters in your string

From Codewars: Count characters in your string, 6 kyu. Uses building a dictionary one key at a time, with .get (session 3).

Write a function count_characters(text). It returns a dictionary. Each key is a character of text, and its value is how many times that character is in text.

For the empty string it returns an empty dictionary.

Put these test lines under your function. A function that works prints the target output.

print(count_characters("aba"))
print(count_characters("banana"))
print(count_characters(""))
target output
{'a': 2, 'b': 1}
{'b': 1, 'a': 3, 'n': 2}
{}
Stuck? Open one hint at a time. The answer is inside the last hint.

Start with an empty dictionary, counts = {}, and look at one character on each pass of the loop.

counts[ch] + 1 gives a KeyError the first time a character is seen, because the key is not there yet. counts.get(ch, 0) gives 0 for a missing key and no error.

Jonathan_codewars.py

def count_characters(text):
    counts = {}
    for ch in text:
        counts[ch] = counts.get(ch, 0) + 1
    return counts

print(count_characters("aba"))
print(count_characters("banana"))
print(count_characters(""))
verified output
{'a': 2, 'b': 1}
{'b': 1, 'a': 3, 'n': 2}
{}

The first time a character is seen, counts.get(ch, 0) gives 0, so the character is stored with the value 1. Every time after that, .get gives the value stored so far and the line adds 1 to it.

10. Rot13

From Codewars: Rot13, 5 kyu. Uses ord, chr and % 26 from the Caesar cipher (session 3).

Rot13 is a Caesar cipher with the key 13: each letter is replaced by the letter 13 places after it in the alphabet, going back to a after z.

Write a function rot13(text). It takes a string of small letters and spaces. It returns the string with every letter moved 13 places. Spaces stay as they are.

Put these test lines under your function. A function that works prints the target output.

print(rot13("hello"))
print(rot13("attack at dawn"))
print(rot13(rot13("attack at dawn")))
target output
uryyb
nggnpx ng qnja
attack at dawn
Stuck? Open one hint at a time. The answer is inside the last hint.

This is shift_by from session 3 with the amount always 13.

For a letter: ord(ch) - ord("a") is its position, counting a as 0. Add 13, use % 26 to go back to the start after z, then add ord("a") back on and use chr.

Jonathan_codewars.py

def rot13(text):
    out = ""
    for ch in text:
        if ch == " ":
            out = out + " "
        else:
            spot = ord(ch) - ord("a")
            spot = (spot + 13) % 26
            out = out + chr(spot + ord("a"))
    return out

print(rot13("hello"))
print(rot13("attack at dawn"))
print(rot13(rot13("attack at dawn")))
verified output
uryyb
nggnpx ng qnja
attack at dawn

The third test line uses rot13 twice and gets the first message back. Moving 13 places and then 13 more is 26 places, and the alphabet has 26 letters, so every letter ends where it started.

Go further. Make capital letters move 13 places as well and stay capital, so that rot13("Hello") returns "Uryyb".
