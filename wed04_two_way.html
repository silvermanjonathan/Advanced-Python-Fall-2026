Section 1 · 10 minutes

Opener: a negative key undoes a positive one

To encrypt a message is to turn plaintext into ciphertext. To decrypt it is to turn the ciphertext back into plaintext. In session 3, the last test line was print(shift_by("gdzq", -3)), and it printed dawn. Moving every letter back 3 undid moving it forward 3.

On paper, predict what each line of this program prints. shift_by is the same function you wrote in session 3. In the last line, the inner call runs first, and its result goes into the outer call.

undo_tour.py, under shift_by

print(shift_by("dawn", 3))
print(shift_by("gdzq", -3))
print(shift_by("abc", -1))
print((0 - 1) % 26)
print(shift_by(shift_by("hello", 7), -7))
Predict first. Lines 1 and 2.
verified output, undo_tour.py
gdzq
dawn

Line 1 encrypts dawn with key 3. Line 2 decrypts the result with key -3 and gets dawn back.

Predict first. Line 3 moves a back 1, past the start of the alphabet. Which letter does it land on? Line 4 is the step inside shift_by that decides it.
verified output, undo_tour.py
zab
25

a is at position 0, and 0 - 1 = -1. % 26 always gives a number from 0 to 25, even when the number before it is negative, so -1 % 26 is 25. Position 25 is z. It is the same wrap as in session 3, run backwards: going forward past z comes around to a, and going back past a comes around to z.

Predict first. Line 5.
verified output, undo_tour.py
hello

7 moves every letter forward and -7 moves it back the same distance. 7 and -7 are opposites: the same size, in opposite directions, so together they add to 0. A shift of 0 changes nothing, so hello comes back. That is the idea for the whole session: decrypting is encrypting with the opposite key.

Section 3 · 40 minutes

Answer with a key

Key presses are events

Pressing a key makes an event, the same way clicking the close button does, and it arrives in the same for event loop. A key event has two things to check:

  • event.type is pygame.KEYDOWN, which means a key went down.
  • event.key says which key: pygame.K_e for E, pygame.K_d for D.

The window only hears keys while it is the active window. If pressing a key does nothing, click the window once, then press the key.

"""Cipher console: the coded message builds up one letter every half second."""

import pygame

import letters

MESSAGE = "attack at dawn"
KEY = 3
ALPHABET = "abcdefghijklmnopqrstuvwxyz"

BOARD = (15, 19, 24)
TILE = (242, 233, 211)
TILE_INK = (27, 31, 38)
CODED_TILE = (31, 46, 39)
CODED_INK = (123, 228, 149)
PLAIN_INK = (150, 143, 128)
GLOW = (201, 139, 31)


def shift_by(text, amount):
    """Return text with every letter rotated forward by amount."""
    out = ""
    for ch in text:
        if ch == " ":
            out = out + " "
        else:
            spot = ord(ch) - ord("a")
            spot = (spot + amount) % 26
            out = out + chr(spot + ord("a"))
    return out


coded = shift_by(MESSAGE, KEY)
coded_row = shift_by(ALPHABET, KEY)
print(f"plain: {MESSAGE}")
print(f"coded: {coded}")
print(f"coded row: {coded_row}")

pygame.init()
screen = pygame.display.set_mode((640, 400))
clock = pygame.time.Clock()

frame = 0
shown = 0
mode = ""
running = 1
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = 0

    screen.fill(BOARD)

    for i in range(26):
        x = 20 + i * 23
        pygame.draw.rect(screen, TILE, (x, 130, 20, 26))
        letters.draw_letter(screen, ALPHABET[i], x + 7, 138, 2, TILE_INK)
        pygame.draw.rect(screen, CODED_TILE, (x, 190, 20, 26))
        letters.draw_letter(screen, coded_row[i], x + 7, 198, 2, CODED_INK)

    if shown < len(MESSAGE) and MESSAGE[shown] != " ":
        spot = ord(MESSAGE[shown]) - ord("a")
        x = 20 + spot * 23
        pygame.draw.rect(screen, GLOW, (x - 3, 127, 26, 32), 3)
        pygame.draw.rect(screen, GLOW, (x - 3, 187, 26, 32), 3)

    letters.draw_word(screen, MESSAGE, 40, 50, 4, PLAIN_INK)
    for i in range(shown):
        letters.draw_letter(screen, coded[i], 40 + i * 16, 280, 4, CODED_INK)

    if mode == "":
        screen.fill(BOARD)
        letters.draw_word(screen, "do you want to", 238, 40, 3, PLAIN_INK)
        letters.draw_word(screen, "encrypt or decrypt", 178, 70, 4, TILE)
        pygame.draw.rect(screen, TILE, (150, 140, 120, 120))
        letters.draw_letter(screen, "e", 192, 170, 12, TILE_INK)
        letters.draw_word(screen, "encrypt", 170, 285, 3, PLAIN_INK)
        pygame.draw.rect(screen, CODED_TILE, (370, 140, 120, 120))
        letters.draw_letter(screen, "d", 412, 170, 12, CODED_INK)
        letters.draw_word(screen, "decrypt", 390, 285, 3, PLAIN_INK)

    frame = frame + 1
    if frame % 30 == 0 and shown < len(MESSAGE):
        shown = shown + 1

    pygame.display.flip()
    clock.tick(60)

pygame.quit()
